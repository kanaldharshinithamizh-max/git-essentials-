# git-essentials-
for non programmers
## STEPS TO CREATE A WEB PAGE 📄
### ✅*STEP 1*
Install git on system.
###  ✅*STEP 2* 
Open command prompt (Shortcut: windows+R).
        Type "git --version" and press Enter(verifies git installation).
###  ✅*STEP 3*
Install VS code (visual studio code).
###  ✅*STEP 4* 
Install codex extension and locate the file path and rename your name.
###  ✅*STEP 5* 
Open codex and click new project, choose the folder with your name.
###  ✅*STEP 6* 
Now type "Create an HTML file welcome your name in this folder. make it look good and fancy.
###  ✅*STEP 7* 
Open the new folder with your name in files. You can see the HTML file created by AI
###  ✅*STEP 8* 
Open the new folder with your name again and click hidden items. Now "git" folder will be visible. This ensures that it is connected with git.
###  ✅*STEP 9* 
Open VS code, press control + O and choose the folder with your name. Now your HTML  code will be visible.
###  ✅*STEP 10* 
Click terminal and type,
(git config --global user.name "your name")
(git config --global user.email "youe email id")
press enter
### ✅*STEP 11*
Click git icon which is top left, them click the source control.
### ✅*STEP 12*
Write commit message "initial commit" and click commit
### ✅*STEP 13* 
Sign in to your Git hub  account 
### ✅*STEP 14*
Click publish branch
### *✅STEP 15* 
Open your github account and check your repository. There you can see the repo of your name with the file inside
